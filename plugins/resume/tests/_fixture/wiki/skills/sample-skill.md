# Node.js

## 요약
REST API 서버 구축 및 비동기 처리 경험. Express 기반 서비스를 직접 개발하고 운영했습니다.

## 근거

### 직접 경험한 것
- Express 기반 REST API 설계 및 구현
- 미들웨어 체인 구성 (인증, 로깅, 에러 핸들링)
- async/await 패턴을 활용한 비동기 처리

### 동작 원리 설명 가능 여부
- 이벤트 루프 개념 설명 가능 (단일 스레드, non-blocking I/O)
