# Mentoring Data Index

이 디렉토리는 멘토링 정제 자료를 저장합니다.

## 파일 규칙
- 위치: `data/mentoring/topics/*.md`
- 파일명: `kebab-case` (예: `problem-solving.md`, `communication.md`)
- 각 파일은 다음 섹션을 권장:
  - `# Topic`
  - `## Core Signals`
  - `## Do`
  - `## Don't`

## PII 정책
- 모든 멘토링 자료는 `data/mentoring/pii-masking-policy.md`를 따른다.
- 미마스킹 자료는 파이프라인 입력으로 사용하지 않는다.
