# Parse Resume PDF (공유 지시블록)

PDF 이력서 → 구조화 마크다운 추출 규칙. 진입점은 `/resume:init <id>`(init 선택 1 PDF 경로)이며, 이 스킬은 그 추출 단계가 따르는 규칙만 정의한다. **입출력 경로는 호출하는 command가 지정**한다(예: 입력 PDF 경로 = 멘티 입력, 출력 = `{MENTEE_ROOT}/raw/resume-original.md`).

## 실행 규칙
1. 지정된 PDF 파일을 Claude가 직접 읽어 텍스트를 추출한다.
2. 추출 결과를 구조화된 마크다운으로 정리한다.
3. 최소 섹션: `## 기본 정보`, `## 경력`, `## 프로젝트`, `## 기술 스택`.

## 실패 규칙
- 입력 PDF가 없으면 실패 메시지를 반환하고 출력 파일을 생성하지 않는다.
- 스캔본·암호화 파일 등으로 텍스트 추출 실패 시 실패 메시지를 반환하고 출력 파일을 생성하지 않는다. 멘티에게 "텍스트로 붙여넣기"(init 선택 1) 경로를 안내한다.
- 실패 시 다음 단계 산출물은 생성하지 않는다.

## 범위 제한
- 외부 OCR/PDF 파서 설치를 요구하지 않는다.
