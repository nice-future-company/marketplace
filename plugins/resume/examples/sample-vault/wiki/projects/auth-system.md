# 회원 인증 시스템

## 요약
핀테크 스타트업 내부 서비스의 회원 인증 모듈을 신규 설계·구현했습니다.
JWT 기반 stateless 인증과 Redis 세션 블랙리스트를 조합한 구조입니다.

## 상세

### 배경
기존 세션 기반 인증이 수평 확장 환경에서 세션 동기화 문제를 일으켰습니다.
MSA 전환 로드맵에 따라 stateless 인증 방식으로 전환하는 작업을 맡았습니다.

### 주요 구현
- JWT Access Token (15분) + Refresh Token (7일) 이중 토큰 구조
- Refresh Token rotation 정책으로 탈취 감지
- Redis 블랙리스트로 로그아웃/강제만료 처리
- 비밀번호 해싱: bcrypt (cost factor 12)

### 인터뷰 수집 내용

#### Why부재 해소 시도
> 추정: JWT 선택 이유로 "MSA 전환 로드맵"을 언급했으나, 구체적 대안 비교(세션 vs JWT vs OAuth2) 근거는 인터뷰에서 추가 확인 필요.
