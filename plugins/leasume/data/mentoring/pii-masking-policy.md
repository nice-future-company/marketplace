# PII Masking Policy

## 목적
멘토링 자료에서 개인식별정보(PII)를 제거해 안전하게 파이프라인에 활용한다.

## 마스킹 대상
- email: `name@example.com` -> `[EMAIL]`
- 전화번호: `010-1234-5678` -> `[PHONE]`
- 회사명: `주식회사 예시` -> `[COMPANY]`
- 개인 이름: 실명 -> `[NAME]`

## 운영 규칙
1. 원문 PII가 포함된 자료는 `data/mentoring/`에 저장하지 않는다.
2. 샘플/예시 파일에도 실제 식별 가능한 문자열을 넣지 않는다.
3. 미마스킹 자료는 파이프라인 입력 금지.

## 점검 체크리스트
- `@` 포함 이메일 흔적이 없는가
- 한국 전화번호 패턴이 남아있지 않은가
- `주식회사`, 법인명, 실명이 그대로 남아있지 않은가
